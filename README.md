# To-Do Task Tracker

A simple task management application built with React.

## Features

* Add new tasks
* Edit existing tasks
* Mark tasks as complete
* Delete tasks
* Save tasks using Local Storage
* Responsive card-based layout

## Technologies Used

* React
* JavaScript
* CSS
* Local Storage

## Installation

```bash
npm install
npm start
```

## Build

```bash
npm run build
```
